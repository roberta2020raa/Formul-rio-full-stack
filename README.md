# Formulário Full Stack — Projeto de Aprendizado

## 📌 Sobre o projeto

Este projeto tem como objetivo compreender, na prática, o caminho percorrido pelos dados de um formulário, desde a entrada das informações pelo usuário no Front-End até seu processamento no Back-End e armazenamento em um banco de dados.

## 🛠️ Tecnologias

- HTML5 — Estrutura do formulário.
- CSS3 — Estilização e responsividade.
- JavaScript — Captura de dados, eventos e validações.
- Node.js e Express — Integração com o Back-End (planejada).
- SQLite — Armazenamento dos dados (planejado).

## 🚀 Etapas do aprendizado

- [x] Criar a estrutura HTML do formulário.
- [x] Estilizar o formulário com CSS.
- [x] Capturar os valores dos campos com JavaScript.
- [x] Trabalhar com o evento `submit` e `preventDefault()`.
- [ ] Concluir as validações dos campos.
- [ ] Criar o servidor com Node.js e Express.
- [ ] Enviar os dados do Front-End para o Back-End.
- [ ] Integrar o banco de dados SQLite.
- [ ] Implementar o cadastro de usuários.

## 🎯 Objetivo

Compreender cada etapa da comunicação entre as camadas de uma aplicação Full Stack, desenvolvendo a lógica e a capacidade de implementar o processo de forma independente.
